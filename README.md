## Tips for clean code

1. Single responsibility is the idea that functions and blocks of code should be responsible for one task. This helps keep code easy to read and makes functions more reusable.
2. Follow the style guide's [patterns](https://github.com/CP1404/Starter/wiki/Programming-Patterns). This makes code easier to read for people also following the same style guide, and makes your code more consistent.
3. [Naming conventions](https://github.com/CP1404/Starter/wiki/Style-Guide#conventions-for-python-names) are important to have readable code that is consistent. This is especially important to help differentiate between different types, as python is dynamically typed.
